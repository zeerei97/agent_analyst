# Cara Kerja Agent Secara Umum
Sistem ini adalah asisten AI modular berbasis LangGraph yang membantu pengguna dalam:
1. Menvisualisasikan dataset secara interaktif menggunakan grafik standar analisis data.
2. Membaca dan menjelaskan informasi/insight dari grafik yang dihasilkan menggunakan Multimodal LLM.
3. Merangkum seluruh penjelasan dari berbagai laporan grafik menjadi satu kesimpulan informasi yang komprehensif.
Framework utama yang digunakan adalah LangGraph dengan model LLM `gemini-3.1-flash-lite`, serta antarmuka pengguna (UI) menggunakan Streamlit dengan tema latar belakang gelap (dark mode) bergaya chatbox.

# agents/visualizer.py
Sub-agen ini bertanggung jawab atas pembuatan visualisasi data menggunakan fungsi-fungsi yang didefinisikan di `tools/visualizer_tools.py`. Langkah kerjanya:
1. Agen memanggil tool untuk mengekstrak struktur dataset (nama-nama kolom beserta tipe datanya).
2. Agen menyajikan informasi kolom tersebut kepada pengguna, lalu membuat grafik sesuai permintaan jenis grafik dan kolom dari pengguna. 
3. Validasi Tipe Data: Jika pengguna meminta jenis grafik yang tidak sesuai dengan tipe data kolomnya (misalnya Scatter Plot pada data kategorikal murni), agen memberikan informasi penolakan dan meminta pengguna menginput ulang pilihan kolom/grafik yang valid.
4. Setelah grafik berhasil dibuat, agen menampilkan grafik beserta nama file-nya dan meminta persetujuan (*Human-in-the-Loop*):
   - Jika "Approved" (ya): Grafik langsung disimpan ke folder `outputs/charts`.
   - Jika "Rejected" (tidak): Agen menanyakan kendala/kesalahan lalu membuat ulang grafik sesuai revisi permintaan.

# agents/interpreter.py
Sub-agen ini berfungsi sebagai pembaca dan penjelas grafik. Langkah kerjanya:
1. Saat pengguna meminta penjelasan grafik tertentu dengan menyebutkan namanya, agen mengambil file gambar grafik dari folder `outputs/charts` dan mengunggahnya ke model LLM.
2. Setelah LLM memberikan kesimpulan/analisis, agen menampilkan hasil tersebut kepada pengguna untuk ditinjau:
   - Jika "Approved" (setuju): Simpan teks ke folder `outputs/reports` berformat `.txt` dengan nama file yang disesuaikan dengan nama grafiknya.
   - Jika "Revision" (revisi): Simpan teks hasil revisi langsung dari pengguna.
   - Jika "Rejected" (tidak setuju): Agen memerintahkan LLM membuat ulang analisis dari awal.

# agents/synthesizer.py
Sub-agen ini berfungsi merangkum seluruh hasil analisis yang tersimpan di `outputs/reports`. Langkah kerjanya:
1. Membaca seluruh file `.txt` di folder `outputs/reports` menggunakan tool yang tersedia.
2. Menampilkan draf rangkuman kepada pengguna untuk ditinjau:
   - Jika "Agree" / "Revision": Simpan hasil akhir yang disetujui ke file `final_analyst.txt`.
   - Jika "Do not Agree": Sub-agen mengulangi proses perumusan rangkuman sampai pengguna menyetujui atau merevisinya.
Catatan: Sub-agen ini TIDAK dijalankan secara otomatis sebelum pengguna memberikan instruksi/keputusan untuk merangkum seluruh laporan.

# visualizer_tools.py
Implementasikan fungsi-fungsi berikut untuk digunakan oleh `agents/visualizer.py`:
1. Line Chart
2. Bar Chart / Column Chart
3. Histogram
4. Box Plot (untuk deteksi outlier)
5. Scatter Plot
6. Correlation Heatmap
7. Fungsi untuk membaca dan mengembalikan daftar nama kolom beserta tipe datanya dari DataFrame pandas.
8. Fungsi untuk memuat dataset (format `.csv`) menggunakan pandas DataFrame dari folder `data/`.

# interpreter_tools.py
Implementasikan fungsi untuk mengambil file gambar grafik (`.png` / `.jpg`) dari folder `outputs/charts` berdasarkan nama file yang diminta pengguna, agar dapat digunakan sebagai tool/input bagi `agents/interpreter.py` ke model LLM.

# synthesizer_tools.py
1. Fungsi untuk membaca dan mengumpulkan seluruh isi file `.txt` dari folder `outputs/reports`.
2. Fungsi untuk menyimpan teks hasil rangkuman akhir yang telah disetujui ke file `final_analyst.txt`.

# state.py
Definisikan class `AgentState` sebagai memori bersama (Central State) graph dengan komponen berikut:
1. `messages`: Annotated[list, add_messages]
2. `visualizer_approved`: bool
3. `interpreter_approved`: bool
4. `current_interpretation`: str (menyimpan teks interpretasi aktif)
5. `synthesizer_approved`: bool
6. `final_summary`: str (menyimpan teks rangkuman akhir)

# workflow.py
Rancang struktur StateGraph LangGraph menggunakan diagram alur berikut:
```mermaid
graph TD
    User([Input File Dataset]) --> Visualizer[Visualizer]
    Visualizer --> GraphicReview{Human}

    GraphicReview -- Approved --> ChartsSaving["Saving @ outputs/charts"]
    GraphicReview -- Rejected --> Visualizer

    ChartsSaving --> Interpreter[Interpreter]
    Interpreter --> InterpretationReview{Human}

    InterpretationReview -- Approved --> ReportsSaving["Saving @ outputs/reports"]
    InterpretationReview -- Rejected --> Interpreter
    InterpretationReview -- Revision --> ReportsSaving

    ReportsSaving -- process the summarization --> Synthesizer[synthesization]
    ReportsSaving -- Create Another --> Visualizer

    Synthesizer --> SynthesizerReview{Human}

    SynthesizerReview -- Agree --> SuccessNode(["End + saving @ final_analyst.txt"])
    SynthesizerReview -- Revision --> SuccessNode
    SynthesizerReview -- Do not Agree --> Synthesizer

main.py
Buat antarmuka aplikasi menggunakan Streamlit dengan ketentuan:

1. Tema latar belakang gelap (dark mode) dan tata letak bergaya chatbox.

2. Di dalam area chatbox, sediakan widget file uploader untuk mengunggah dataset berformat .csv. Setelah diunggah, file wajib disimpan ke folder data/.

3. Alur interaksi pengguna:

- Pengguna mengunggah dataset yang bersih.

- Pengguna mengetikkan instruksi atau pertanyaan mengenai apa yang ingin dilakukan pada file tersebut.

- Sistem agen berjalan interaktif menangani siklus visualisasi, interpretasi, hingga rangkuman.

- Perulangan chat berjalan terus sampai pengguna mengetikkan kata kunci exit atau done.

- Setelah selesai, tampilkan ringkasan hasil akhir kepada pengguna.
